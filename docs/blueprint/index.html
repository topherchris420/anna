R.A.I.N. DataMatrix Engine — blueprint animation

A 62-second technical animation of how the engine turns sources into a citable answer, in nine stages:

  1. System initialization.
  2. Knowledge sources: twelve source plugins feed the ingestion trunk.
  3. Modular ingestion: a five-stage pipeline normalizes every source into one Document shape and merges duplicates.
  4. Dual index construction: lexical strips and 384-dimension semantic vectors are written into the engineering_docs index.
  5. Query split: a hybrid query fans out to a BM25 retriever and a kNN retriever, each building its own ranked list.
  6. Reciprocal Rank Fusion: the two rankings are fused by score(d) = sum of weight_i / (k + rank_i(d)), with k = 60.
  7. Citation-first answer: the answer is assembled from retrieved evidence, with every claim carrying a citation to its source document.
  8. Graceful degradation: four fallbacks reroute around missing components so the core search path is preserved.
  9. Complete exploded view: the whole architecture in one frame.

The transport controls below the frame play, pause, restart, scrub and explore the system map. Keyboard: space plays or pauses, arrow keys seek, R restarts, E toggles Explore mode.
